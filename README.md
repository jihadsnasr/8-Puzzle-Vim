# 8 Puzzle Vim

A sliding puzzle game for Windows that uses Vim keys to move the tiles.

I made this to mix Vim with a fun game. Getting good at the puzzle means practicing Vim motions, making it a fun way to learn the basics.

## Installation

1. Download `8 puzzleVim.exe` from this repository.
2. Double-click the executable to launch the game.

No installer or setup wizard required.

**Requirements:** Windows with .NET Framework 4.7.2 or later.

## Controls

| Key | Action |
| --- | --- |
| `H` `J` `K` `L` | Move a tile into the empty space |
| `S` | Shuffle a new puzzle |

The theme button cycles through six color themes.

## Features

- Timer that starts with your first move
- Random scrambles that are always solvable
- Six color themes
- Online leaderboard to compare your completion times with other players

## Leaderboard

Compete with other players and see how your solving time ranks.

- Submit your username and completion time.
- View the leaderboard to compare your results with other players.
- Rankings are based on completion time. Lower times earn higher positions.

No account or sign-up required.

## Learn the Basics of Vim

In Vim, `h`, `j`, `k`, and `l` move the cursor:

- `h` moves left
- `j` moves down (it looks like a down arrow)
- `k` moves up
- `l` moves right

Use these keys in the game and you'll build the muscle memory you need for Vim.
